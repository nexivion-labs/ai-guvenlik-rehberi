# Sözlük

[← İçindekiler](README.md)

| Terim | Açıklama |
|---|---|
| **Ajan (AI agent)** | Yalnız cevap vermekle kalmayıp dosya okuyan, komut çalıştıran ve araç kullanan yapay zekâ uygulaması. Ör. Claude Code. |
| **API anahtarı** | Bir hizmete programla erişmek için kullanılan gizli değer. Şifre gibi korunmalıdır. |
| **Atlama kipi (bypass permissions)** | Ajanın hiç onay istemeden her şeyi yapabildiği kip. Claude Code'da `--dangerously-skip-permissions`. |
| **Delil paketi** | Olay incelemesinde toplanan, değiştirilmediği hash'lerle kanıtlanan metin dosyaları. |
| **Dev Container** | Geliştirme ortamını ana bilgisayardan yalıtılmış bir konteynerde çalıştırma yöntemi. |
| **Hash (SHA-256)** | Bir dosyanın parmak izi. Dosyada tek bir bayt değişse hash tamamen değişir. |
| **Hook** | Ajanın belirli olaylarda (ör. bir komut çalıştırmadan önce) otomatik çalıştırdığı komut. |
| **İki adımlı doğrulama (2FA)** | Şifreye ek olarak ikinci bir kanıt (uygulama kodu, güvenlik anahtarı) isteyen giriş yöntemi. |
| **İstem enjeksiyonu (prompt injection)** | Ajanın okuduğu içeriğe gizlenmiş talimatların ajanı yönlendirmesi. |
| **Karartılmış kod (obfuscated)** | Okunmasını zorlaştırmak için bilerek bozulmuş kod. Zararlı yazılımda sık görülür. |
| **Kilit dosyası (lockfile)** | `package-lock.json` gibi, kurulacak her paketin tam sürümünü ve hash'ini sabitleyen dosya. |
| **MCP (Model Context Protocol)** | Ajanlara dış araç ve veri kaynakları bağlamak için kullanılan protokol. |
| **MCP sunucusu** | Ajana yeni araçlar sağlayan program ya da hizmet. Yerel olanlar bilgisayarınızda çalışır. |
| **Oturum anahtarı / token** | Giriş yaptıktan sonra sizi tanıyan değer. Ele geçirilirse şifre olmadan girilebilir. |
| **Push protection** | GitHub'ın, içinde sır bulunan bir commit'in gönderilmesini engelleyen özelliği. |
| **Sandbox** | Bir programın erişebileceği dosya ve ağ adreslerini işletim sistemi düzeyinde sınırlayan yalıtım. |
| **Settings Sync** | VS Code ayarlarını ve eklenti listesini cihazlar arasında eşitleyen özellik. |
| **Tedarik zinciri saldırısı** | Doğrudan size değil, kullandığınız bir pakete ya da araca saldırıp sizin üzerinizden yayılma. |
| **Typosquatting** | Bilinen bir paketin adına çok benzeyen adla zararlı paket yayımlamak (ör. `reqeusts`). |
| **VSIX** | VS Code eklenti paketi. Aslında bir ZIP arşividir. |
| **Workspace Trust (Çalışma Alanı Güveni)** | VS Code'un, güvenilmeyen klasörlerde kod çalıştıran özellikleri kısıtladığı kip. |
